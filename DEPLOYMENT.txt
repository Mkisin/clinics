Перед публикацией

Текущее размещение:
  Каталог сервера: /srv/projects/clinics
  Сервис: clinics.service, порт 127.0.0.1:3011
  Основной домен: clinic-forum.ru (BASE_PATH пустой)
  Временный адрес: http://200.165.228.35/clinic-forum/
  Для временного адреса nginx удаляет /clinic-forum/ при передаче в Node.js:
    location = /clinic-forum { return 308 /clinic-forum/$is_args$args; }
    location ^~ /clinic-forum/ { proxy_pass http://127.0.0.1:3011/; ... }
  Относительные пути ресурсов и API работают в обоих вариантах.
  После смены DNS на 200.165.228.35 необходимо выпустить HTTPS-сертификат.

1. Запускать сайт через Node.js (npm start). Сервер слушает 127.0.0.1:3010.
   Не публиковать корневую папку проекта как каталог статических файлов.
   .env хранится только на сервере, вне доступа веб-сервера, с правами для
   пользователя приложения (на Linux: chmod 600 .env).

2. Если перед Node.js стоит nginx на том же сервере:
   установить TRUST_PROXY=loopback в .env;
   проксировать запросы на http://127.0.0.1:3010;
   перезаписывать заголовок: proxy_set_header X-Forwarded-For $remote_addr;
   не принимать присланный посетителем X-Forwarded-For как достоверный IP.
   Если используется CDN или другой прокси, настроить доверенные адреса отдельно.
   BASE_PATH задаётся только при размещении сайта в подпапке домена.

3. Не отключать проверку TLS-сертификатов. Webhook использует HTTPS;
   перенаправления запроса CRM запрещены, ошибки не возвращают секретный URL.

4. После публикации повторить HTTP-проверки на публичном домене:
   /.env, /server.js, /api/register.js, /.git/config и варианты обхода пути
   должны быть недоступны. Проверить настоящий IP посетителя за прокси.

5. Первичная защита без CAPTCHA: honeypot, 5 попыток / 10 минут на IP,
   блокировка повторных/параллельных заявок с одинаковыми email и телефоном
   на 10 минут, проверка полей и согласия на сервере, предел JSON 32 КБ.
   Счётчики хранятся в памяти одного процесса и сбрасываются при перезапуске.
   Для нескольких процессов требуется общее хранилище ограничений.

Локальные проверки:
  python -X utf8 scripts/audit_program.py
  npm test

Тесты используют подменённый ответ CRM и не создают реальные лиды.
